Introduction to JupyterLite

In this course we will use JupyterLite to work with Python for data analysis.

JupyterLite is a browser-based version of Python that allows us to get up and running quickly without having to install anything on our machines. The exercises you’ve done in the “Introduktion til Livets Molekyler” course use the same technology under the hood, but we will now use a more full-fledged version as we work towards doing more complex tasks with Python.

1 JupyterLite Introduction

JupyterLite can be accessed at this webpage: https://au-mbg.github.io/jupyterlite-playground/lab/index.html

When you first access the page, you should see something like what is shown in Figure 1

JupyterLite is a JupyterLab distribution that runs in the browser. This means you can run Python programs and notebooks in JupyterLite without having to install anything.

2 Working with notebooks in JupyterLite

On the home page of JupyterLite, also called the launcher, you can click the button that says Python (Pyodide) to create a new notebook. You will then arrive at a page like the one shown in Figure 2.

This notebook is a document that can contain both code and text, with the two types separated into different cells, see Figure 3. The Python you worked with in IMOL is very similar to one of these code cells.

To see the output produced by code in a notebook, we need to run or execute its code cells. There are several ways to control cell execution, see Figure 4 and the list below:

  • ▶: Runs the currently selected cell. You can also use the keyboard shortcut .
  • ▶▶: Restarts the notebook and runs all cells from top to bottom.
  • ⏹: Stops execution. This is useful when code keeps running without finishing or when you notice a mistake and do not want to wait for execution to finish.
  • ↻: Restarts the notebook without running the cells again.
  • Run: Opens a menu with additional options for running cells.
NoteRun cells in order

When you open an exercise, start at the top of the notebook and run the cells in order. The first setup cell may take a little longer to run because it prepares the course software. If you restart the notebook, run the cells from the top again before continuing your work.

3 Opening course notebooks

The exercises in this course are provided as notebooks that can be opened directly in JupyterLite. On the course website, open the exercise you want to work on and click Open in JupyterLite under Other Formats, see Figure 5

JupyterLite will open and import a copy of the exercise notebook. If the notebook does not open automatically, locate it in the JupyterLite file browser and double-click it.

Alternatively, click Notebook to download the notebook to your computer. You can then upload it to JupyterLite as described below.

4 Notebooks as files

Opening a saved notebook

To continue working on a notebook that is stored on your computer, upload the .ipynb file to JupyterLite. Click the ⬆ button in the JupyterLite file browser and select the notebook using your computer’s file browser. Once the notebook appears in the JupyterLite file browser, double-click it to open it. This is shown in Figure 8.

Persistent storage in JupyterLite

As you use JupyterLite, you will notice that it also saves your work. However, this is done in your browser’s local storage. You should NOT rely on this as a mechanism to store your notebook long term, as it may be reset by, for example, clearing your browser history or cookies. It will also not persist if you use another browser or another machine.

5 Data files

Many of the exercises we will work on in the course are about analyzing data and often this data will come in the form of files, such as .csv or .xlsx.

You should also store these data files on your machine in the same folder (or a subfolder) as you store the notebooks. The screenshot below illustrates one way of managing this.

Warning

Reproducing results, including data analysis, is essential in science. It is therefore important to develop good data-management practices that allow you to return to data you have worked with previously.

You will need to upload these files to JupyterLite to work with them. Use the same ⬆ button described above for uploading a saved notebook, then select the data file using your computer’s file browser.

JupyterLite has its own file system in your browser. Uploading a file creates a separate copy in this file system; it does not create a live connection to the original file on your computer. If you change the original file, you will need to upload it again for those changes to become available in JupyterLite.

It is generally easiest to keep the notebook and its data files in the same folder in JupyterLite. A file in the same folder as the notebook can be referred to by its filename, for example experiment.xlsx. If you organize your data in a subfolder called data, the corresponding relative path is data/experiment.xlsx.

6 Working with file paths.

When you want a program to read file it needs to know where the file is this is called a “file path” (en fil sti in danish). There is no wiggle-room with these file paths, they need to be exactly correct, computers are not smart enough to know that if you asked for dataa/abc.csv but only data/abc.csv exists you probably meant that.

The file system on a computer can be represented by a tree-structure, similar to a family tree. For example, the files in Figure 9 can be represented by a tree like so

fysisk_biokemi
├── data
│  ├── averag-prope-amino-acids.xlsx
│  ├── trypt-absor-fluor-emission.xlsx
│  └── trypt-absor-fluor-extinction.xlsx
└── jupyterlite_intro.ipynb

We see that fysisk_biokemi is a directory, that directory contains another directory data and a file jupyterlite_intro.ipynb, the data folder contains three files.

When working in a notebook, we specify paths relative to the folder containing the notebook. You can think of the notebook as the program that is reading the file. The examples below show how the path changes when the notebook is placed in different folders.

NoteThe notebook is inside the fysisk_biokemi folder

Consider the same tree with the notebook inside the fysisk_biokemi folder:

fysisk_biokemi
├── data
│  ├── averag-prope-amino-acids.xlsx
│  ├── trypt-absor-fluor-emission.xlsx
│  └── trypt-absor-fluor-extinction.xlsx
└── jupyterlite_intro.ipynb  ← notebook running from here

The relative path to one of the data files would then be data/averag-prope-amino-acids.xlsx. Starting from the folder containing the notebook, we first enter the data folder and then find the file averag-prope-amino-acids.xlsx.

NoteThe notebook is outside the fysisk_biokemi folder

If instead the notebook were located outside the fysisk_biokemi folder, the tree would look like this:

.
├── jupyterlite_intro.ipynb  ← notebook running from here
└── fysisk_biokemi
   └── data
      ├── averag-prope-amino-acids.xlsx
      ├── trypt-absor-fluor-emission.xlsx
      └── trypt-absor-fluor-extinction.xlsx

The relative path to the same data file would then be fysisk_biokemi/data/averag-prope-amino-acids.xlsx. Starting from the notebook, we first enter the fysisk_biokemi folder, then the data folder, and finally find the file.

NoteThe notebook is in another folder inside fysisk_biokemi

Finally, the notebook could be located in a separate folder inside fysisk_biokemi, as illustrated by this tree:

fysisk_biokemi
├── data
│  ├── averag-prope-amino-acids.xlsx
│  ├── trypt-absor-fluor-emission.xlsx
│  └── trypt-absor-fluor-extinction.xlsx
└── program
   └── jupyterlite_intro.ipynb  ← notebook running from here

In this case, the relative path to the data file is ../data/averag-prope-amino-acids.xlsx. Here, ../ means “go up one folder.” Starting from the program folder, we first go up to fysisk_biokemi, then enter the data folder and find the file.

Summary and tips for working with notebooks

  • Start at the top of a notebook and run its cells in order. Later cells may depend on variables or packages created by earlier cells.
  • Editing a cell does not run the new code. Run the cell again after making a change.
  • If you change an earlier cell, rerun the cells that depend on it. When in doubt, restart the notebook and run all cells from the top.
  • Use the stop button if a cell keeps running without finishing.
  • When Python reports an error, read the final line of the error message first. It usually gives the most useful description of what went wrong.
  • Before loading a data file, check that it is visible in the JupyterLite file browser and that its path matches its location.
  • JupyterLite saves work in the browser, but this storage is not a reliable long-term backup. Regularly export your notebook as an .ipynb file and store it on your computer.

### Summary and tips for working with notebooks

- Start at the top of a notebook and run its cells in order. Later cells may depend on variables or packages created by earlier cells.
- Editing a cell does not run the new code. Run the cell again after making a change.
- If you change an earlier cell, rerun the cells that depend on it. When in doubt, restart the notebook and run all cells from the top.
- Use the stop button if a cell keeps running without finishing.
- When Python reports an error, read the final line of the error message first. It usually gives the most useful description of what went wrong.
- Before loading a data file, check that it is visible in the JupyterLite file browser and that its path matches its location.
- JupyterLite saves work in the browser, but this storage is not a reliable long-term backup. Regularly export your notebook as an `.ipynb` file and store it on your computer.
